html

html significa (hypertext markup language), é uma linguagem web, utilizada para fazer sites com todos os elementos de estrutura web sendo elas:

  • title: é o titulo da pagina que aparece no canto esquerdo da tela, que contem o nome da pagina
  • p: a tag "p" significa um paragrafo no site
  • h1,h2,h3... significa um subtitulo da pagina

enfim existem inumeras tags para o html, em breve criaremos um sites explicando todas as tags de html e suas funções.

para que serve?

  • parte visual o front-end de um site,aplicativo ou jogos
  • incoporação de midias como imagens, videos e audios
  • organização de conteudos em blogs,e-mails e redes sociais

quem criou?

tim berners-lee, foi o inventor do html em 1990, enquanto trabalhava no cern (organização europeia para pesquisa nuclear), com o objetivo de facilitar o compartilhamento de documentos entre pesquisadores atraves do hypertexto, estabelecendo a base para o world wide web o ("www")

é uma linguagem de programação?

a resposta é não, o html faz parte do campo de ciencias da computação, porem não é uma linguagem de programação. somente apenas uma linguagem de marcação de texto.
