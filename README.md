
# Verificador de Gênero e Projetos de Faculdade

### Sobre o Projeto
Este repositório reúne scripts simples em Python desenvolvidos para fins de aprendizado acadêmico na faculdade. O programa principal realiza a validação e definição de gênero com base na entrada do usuário, tratando dados inválidos.

### Funcionalidades
* Validação de entrada de texto para termos masculinos e femininos.
* Tratamento de erros para palavras inválidas.
* Inclui projetos complementares de lógica de programação (Calculadora e Simulador de Banco).

* **Linguagem usada:** Python
